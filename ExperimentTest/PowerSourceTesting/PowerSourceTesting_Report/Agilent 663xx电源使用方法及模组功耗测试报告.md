## 二、Agilent 663xx 电源仪器使用方法

本章依据《Agilent 14565A Device Characterization Software Quick Start Guide》整理，按照"仪器概述 → 安装配置 → 基本操作 → 触发测量 → 波形分析 → 高级功能 → 数据管理 → 注意事项"的顺序，介绍通过 14565A 软件使用 Agilent 663xx 系列直流电源的完整方法。

### 2.1 仪器与 14565A 软件概述

Agilent 66300 系列（663xx）直流电源是面向移动设备/电池供电设备测试的直流源，配合 Agilent 14565A Device Characterization Software（设备特性分析软件）使用时，可将电源扩展为"直流源 + 示波器 + 数据记录仪"的一体化测试平台。14565A 软件在 PC 上运行，提供图形化界面，主要功能包括：

- 在单一窗口内控制电源输出（电压、限流、输出电阻）并查看测量结果；
- 以类似示波器的方式显示输出电压/电流波形，支持触发测量；
- 复制、保存、打印捕获的波形，并可加载已保存的参考波形与实时波形进行同屏对比；
- 通过水平/垂直游标（Marker）对波形选定区段进行精确测量；
- 支持仿真模式（Simulation，无需连接硬件即可练习）和仪器控制模式；
- 长时间电压/电流数据记录（Long Term Data Logging）；
- 生成电池电流消耗的 CCDF（互补累积分布函数）图（仅限 66319B/D、66321B/D 且固件版本 A.03.00 及以上）。

该软件的局限：仅支持 Agilent 直流电源，不能控制其他厂商仪器，也不为其他 GPIB 仪器提供驱动。

### 2.2 支持的型号与系统配置要求

14565A 软件支持的直流电源型号包括：66309B/D、66311A/B/D、66312A、66332A、66319B/D、66321B/D。其中 66319B/D 和 66321B/D 功能最全；其余型号不支持 CCDF 测量和长时间数据记录功能。双路输出控制仅 66309B/D、66319B/D 具备；DVM（数字电压表）输入仅 D 后缀型号（66311D、66309D、66319D、66321D）具备。

计算机端配置要求：

- 硬件：Pentium 233 MHz 及以上、64 MB 及以上内存；
- 操作系统：Windows 98 / NT 4.0 / 2000 / XP；
- 接口库：Agilent IO Library K.01.00 及以上（现对应 Keysight IO Libraries Suite），或 NI VISA Run-time Engine 2.6；
- 接口卡：Agilent 82350A / 82341C GPIB 卡、NI GPIB 卡（需 NI-488.2 Win32 1.6 及以上），或使用 RS-232 串口直连。

### 2.3 软件安装与 I/O 通信配置

安装前须先将直流电源通过 GPIB 电缆或串口线连接至计算机，安装并配置好接口卡及驱动，并确认电源已开机。安装步骤：

1. 运行安装盘中的 Agilent14565A.exe，按屏幕提示完成安装；安装目录下的 Readme.txt 包含联机帮助中未记录的产品更新信息，可用文本编辑器查阅；
2. 双击桌面图标，或通过"开始 → 程序 → Agilent Technologies → 14565A Device Characterization Software"启动软件。

通信配置在 Source 菜单的 I/O Configuration 中完成（关闭仿真模式时该界面会自动弹出）。配置要点：

- I/O 类型可选 Simulation（仿真）、HP-IB、GPIB、VISA 或 Serial（串口）；
- 使用 GPIB/HP-IB 时，软件中填写的地址必须与电源本机地址一致；HP-IB 卡还需填写与卡配置一致的 SICL 名称；
- 使用串口时，需选择正确的 COM 口，且波特率、校验位、流控必须与电源端设置完全一致；
- 无法通信时可点击 Auto Detect 自动搜索已连接的电源；
- 注意：数据记录（Data Logging）和 CCDF 功能必须使用 VISA 接口类型。

> **特别提示：** 软件运行期间若在电源前面板上修改过设置，软件不会自动同步，须通过 View → Reread Instrument State 手动刷新仪器状态。

### 2.4 基本操作

软件主窗口集成了输出控制与测量显示，基本操作流程如下：

1. 设置输出参数：在 Voltage 栏输入输出电压并回车；在 Current 栏输入限流值；对支持程控输出电阻的机型，在 Resistance 栏输入电阻值；
2. 开启输出：将输出滑动开关拨至 ON（双路输出机型每路有独立开关）。若显示 OVLD（过载）信息，将 Current Measurement 量程切换到 Hi Range 即可；
3. 执行测量：点击 A 按钮选择电流测量、V 按钮选择电压测量，再点击 Measure 按钮采集波形（新测量会覆盖旧波形）；
4. 调整显示：修改 time/div（时基/采样率）和 amps/div（垂直刻度）字段，或点击 Auto Scale 使波形自适应显示；
5. 显示第二路输出/DVM：在 View 菜单勾选 Second Output 或 Digital Voltmeter（菜单项为灰色表示该机型无此硬件）。

显示区底部会自动给出由全部捕获数据计算得到的测量值，包括最大值（Max）、最小值（Min）、高电平平均值（High）和低电平平均值（Low）；设置了水平游标后，仅计算游标之间的数据。由于显示采样率与电源前面板采样率可能不同，软件计算值与前面板读数可能略有差异，属正常现象。

### 2.5 触发测量

触发测量用于精确控制波形捕获时机，适合捕捉开机浪涌、模式切换等瞬态电流。操作步骤：

1. 选择 A（电流）或 V（电压）测量，并将 time/div 设置为与负载瞬态时间相匹配的值；
2. 设置触发方式：Auto Trig（自动触发）、Pos Slope（上升沿）、Neg Slope（下降沿）、Either Slope（双沿）或 External（外部触发，经 Output Port 接口接入外部触发信号）；
3. 调节 Level 滑杆设定触发电平，显示为红色水平线。注意触发电平不能设为负值，捕捉负向波形须使用 Auto Trig；
4. 使用 Pre-Trigger 控制显示触发点之前的波形，触发点在波形图底部以红色短竖线标示；
5. 使用 Num. Sweeps 设置扫描次数，对多次电流脉冲的高电平进行平均，提高测量准确度；
6. 若信号噪声导致误触发，可调节 Hysteresis（迟滞）滑杆在触发电平周围形成迟滞带（黄色显示），迟滞带内不会触发；
7. 点击 Measure 开始触发测量；若长时间未收到触发信号，仪器将超时退出。采集完成后可调节 amps/div 或按 Auto Scale 优化显示。

> **实用技巧：** 不确定触发电平时，先用 Auto Trig 采集一次波形，观察波形幅度后再设定触发电平重新测量。

### 2.6 波形分析：游标测量、缩放与参考波形对比

**游标测量：** 点击工具栏游标按钮显示水平游标（X1、X2）和垂直游标（Y1、Y2），用鼠标拖动定位。显示区同时给出各游标位置及其差值，所有计算值均基于 X1 与 X2 之间的数据，可对波形的任意区段进行精确测量。

**缩放：** 点击工具栏放大按钮或用鼠标在显示区框选目标区域即可局部放大；在显示区右键选择 Zoom Out 还原。缩放仅改变显示比例，不影响测量计算结果。

**参考波形对比：** 通过 File → Load Waveform 最多可加载两条参考波形与实测波形同屏显示（颜色可在 Edit → Preferences 中修改），便于与"标准波形"对比、进行合格/不合格判定。加载时选择 Active Waveform 才能对加载波形进行测量计算（会覆盖当前显示）；作为参考波形加载则不覆盖显示，但不能对其进行游标计算。数据记录和 CCDF 波形只能作为参考波形加载。

### 2.7 CCDF 图（电池耗电统计分析）

CCDF（Complimentary Cumulative Distribution Function，互补累积分布函数）图以幅度为横轴、出现概率（%）为纵轴，用于简明汇总短期和长期的电池耗电数据，特别适合分析随时间随机变化的电流（如整机的动态耗电）。该功能仅限 66319B/D、66321B/D（固件 A.03.00 及以上）。

**工作原理：** 测量开始后按设定采样率连续采样，软件建立 2048 个桶（bucket）构成的直方图，每个样本按幅度归入对应桶并计数；超出直方图范围的样本归入两端桶。测量过程中直方图数据经归一化、累加并按 100%→0% 重排，生成 CCDF 曲线。

**操作步骤：** 点击 CCDF 按钮进入测量窗口 → 选择测量对象（Current / Voltage / DVM）→ 电流测量时选择量程（High/Medium/Low），测量类型（Type）推荐选 Pulse（波形测量精度最佳）→ 设置采集时长 Acquisition Period（hhhh:mm:ss）→ 点击 Measure 开始。采集期间界面周期刷新，Remaining Period 显示剩余时间。

> **注意：** 采集期间不要修改左侧前面板控件，否则会改变数据采集条件导致数据失效；长时间测试建议启用屏保密码防止他人误操作。

### 2.8 长时间数据记录（Long Term Data Logging）

长时间数据记录可连续数小时至数天记录被测设备的电流和电压，是测量整机功耗、评估电池续航时间的基础手段。该功能同样仅限 66319B/D、66321B/D（固件 A.03.00 及以上）。测量对象可选：输出 1 电流、输出 1 电流+电压，或输出 1 电流+DVM 输入。

**工作原理：** 电流以 15.6 μs 高速采样，在每个积分周期（5 ms～1 s 可选）内积分，返回三个值——DC（积分周期内全部样本的平均值）、Max（最高样本值）和 Min（最低样本值）；选择电压测量时按固定间隔同步记录电压。图形区以不同颜色分别显示 Max、DC、Min 三条电流曲线；选择 Grey Band 模式时以灰色带表示 Min～Max 范围、红线表示 DC 值，电压以蓝线显示在图形上方。数据填满显示区后会自动扩大分辨率以容纳更多数据。

**操作步骤：** 点击 Data Logging 按钮进入记录窗口 → 选择测量模式（Current / Voltage+Current / DVM+Current）→ 选择电流量程（High/Medium/Low）→ 测量类型推荐 Pulse → 设置记录时长（hhh:mm:ss，定时器最小分辨率 3 秒）→ 勾选要显示的曲线（Max/DC/Min/Gray Band）→ 点击 Measure 开始。记录结束后软件提示将数据保存为二进制文件。

### 2.9 数据保存、打印与导出

- **保存波形：** File → Save Waveform 将测量数据保存为 ASCII 文本。普通波形为 2 列（时间/电压或时间/电流）；CCDF 为 2 列（幅度/% 概率）；数据记录为 5 列（时间、CurrentMax、CurrentDC、CurrentMin、电压）。文本可直接导入 Excel、数据库或文本编辑器，也可用于制作参考波形；
- **打印：** File 菜单提供 Print Preview（打印预览）和 Print（打印）显示内容；
- **导出数据记录：** File → Export Data Log to Excel/Text 可将二进制记录文件导出为 Excel 或文本，支持选择整段或部分时段导出，并可设置数据抽稀比例以控制文件大小；
- **数据记录转 CCDF：** File → Convert Data Log to CCDF 可将已保存的数据记录文件（全部或指定时段）转换为 CCDF 图进行分析（仅在 CCDF 模式下可用）。

### 2.10 高级设置与使用注意事项

高级设置集中在 Source 菜单：

- **Measurement Settings：** 设置电流量程、测量类型、积分窗函数和采样时间；
- **CCDF Settings / Data Logging Settings：** 与对应测量窗口参数一致，其中积分时间和数据文件保存目录只能在设置窗口中配置；
- **Source Settings（保护设置）：** 设置过压保护（OVP）限值、过流保护（OCP）使能及延时、按接线和输出带宽选择补偿模式，并可将仪器状态保存/调用到非易失存储器；
- **Edit → Preferences：** 设置表头刷新率、网格线、波形标记显示与波形颜色，可恢复出厂默认值。

**使用注意事项汇总：**

1. 开始任何测量前，确认接口连接正常、软件中仪器地址/串口参数与电源一致；
2. 设置输出时务必先设好限流值（Current），再开启输出，防止被测模组过流损坏；
3. 出现 OVLD 提示时先切换电流测量量程至 Hi Range；
4. 触发测量时合理设置触发电平、迟滞带和扫描平均次数，兼顾灵敏度与抗干扰；
5. 长时间记录/CCDF 采集期间不得更改任何输出设置，并对电脑加锁防误操作；
6. 软件修改与前面板修改不会自动同步，前面板操作后须执行 Reread Instrument State；
7. 出厂附带 5 个示例波形（如 DemoWaveform1.txt），可在仿真模式下加载练习各项显示与分析功能。

## 三、电源操作方法与模组功耗测试方法

### 3.1 测试前准备

测试电脑，测试板 Test.Tool.V91，Agilent 66311B 电源，安装 Agilent 14565A 驱动，被测模组 BF85112B。

### 3.2 电源操作方法要点

结合实验室现有 Agilent 66311B 电源的实际操作流程：开机自检、输出电压与限流设置、输出开启/关闭、读数方法（前面板与 14565A 软件）。

### 3.3 模组功耗测试方法

各测试模式（Idle / FingerDetect / Capture）的进入方式、电流量程选择（Hi/Low Range 对测量分辨率的影响）、平均电流与峰值电流的读取方法（波形测量 + 游标 / 数据记录）、采样时长与重复次数约定。

- **Idle 模式：** 首先初始化，然后下载相应工单之后直接点击 Measure，观察记录相应测量值。
- **FingerDetect 模式：** 将模组测试工具面板里的寄存器配置改为 34、写入 02、读取，点击 Measure，可以观察到相应图形以及被测数值，可以选择不同的 time/div 看多个周期。
- **Capture 模式：** 若已经进行 FingerDetect 模式测量，则要重新初始化并下载，然后点击模组测试工具面板里的连续采图，之后即可观察相应波形，通过游标测量其上升沿、下降沿的时间，以及周期等等。

### 3.4 测试安全与注意事项

限流保护设置、防静电措施、接线检查、异常处理流程。

## 四、模组功耗实操测试

本章记录模组功耗的实操测试过程与结果，包括测试环境、测试步骤、各模式电流数据记录及结果分析。

### 4.1 测试环境与设备

| 项目 | 配置 / 参数 |
| --- | --- |
| 直流电源 | Agilent 66311B（移动通信直流源） |
| 上位机软件 | Agilent 14565A Device Characterization Software（固件 A.02.04，经 NI GPIB 连接） |
| 供电电压 | 3.3 V（电源显示实测 3.299 V，CV 恒压模式） |
| 限流设置 | 3.07125 A |
| 测量量程 / 类型 | Low（<0.02 A）/ Pulse（脉冲测量，波形精度最佳） |
| 显示时基 | 50 ms/div 或 100 ms/div（按模式电流周期选择） |
| 被测模组 | BF85112B（指纹模组），共 2 个样品 |
| 测试日期 | 2026 年 8 月 11 日（样品 1）、8 月 12 日（样品 1 复测 + 样品 2） |

### 4.2 测试步骤

1. 连接测试板与转接板 SPI 信号引脚以及 AVDD 引脚，先进行模组测试软件的初始测试，确保可以正常测试进入开发者模式。
2. 测试板在测试模组中测试通过，Ctrl+B+F 打开开发者模式。
3. 打开电源 On，将 USB 与电脑连接，打开 Agilent 14565A DCS 软件，选择 GPIB，并 Auto Detect。
4. 设置 Voltage 3.3 V，Range 选 Low。
5. 打开选择工单，初始化并下载。
6. 拔掉 MOSI 防漏电，测试 Idle 模式，点击 Measure。
7. 接回 MOSI 并点击连续采图模式，测试 Capture 模式。
8. 停止连续采图，一键初始化并下载，地址写 34、值写 02，之后进行写-读-写并测量 FD 模式。
9. 完成 FD 模式测量后，将 Output 点击 Off 并退出软件，完成测试。切换不同周期工单进行测量，同一套流程。

### 4.3 测试数据记录

本次共测试 2 个同型号（BF85112B）模组样品。供电电压：**3.3 V**（电源实测 3.299 V，CV 模式）。平均电流取软件计算值 Dc，峰值电流取 Max。两样品各模式代表值（6 个检测间隔组的均值）汇总如下：

**表 4-2　两样品各工作模式电流汇总表（代表值）**

| 测试模式 | 样品 1 平均电流 | 样品 1 峰值电流 | 样品 2 平均电流 | 样品 2 峰值电流 |
| --- | --- | --- | --- | --- |
| Idle 模式 | ≈ 3.8 µA | ≈ 6.9 µA | ≈ 4.0 µA | ≈ 6.9 µA |

### 4.4 测试结果分析

**（1）各模式功耗对比。** 三种模式的功耗层级差异显著：Idle 模式平均电流约 3.8~4.0 µA（约 13 µW），FD 模式约 5.2~5.4 µA（约 17 µW），Capture 模式约 1.9 mA（约 6.2 mW）。Capture 模式平均电流约为 FD 模式的 360 倍，说明模组的功耗绝大部分来自图像采集动作，待机与手指检测状态下的功耗控制良好。

**（2）样品间一致性。** 两个同型号样品的测量结果高度一致：Idle 平均电流偏差约 5%（3.8 µA vs 4.0 µA），FD 平均电流偏差约 4%（5.2 µA vs 5.4 µA），Capture 平均电流偏差约 1%（1.88 mA vs 1.86 mA），峰值电流均稳定在约 16.9 mA。表明该型号模组的功耗特性个体差异小，测量方法与数据均可信。

**（3）FD 模式平均电流与检测间隔的关系。** FD 波形为"数 µA 基线 + 周期性检测脉冲（约 225~314 µA）"，脉冲间隔与设定的检测间隔一致。检测间隔越长，单位时间内脉冲次数越少，平均电流越低：样品 1 由 50 ms 时的 7.97 µA 降至 300 ms 时的 3.69 µA，样品 2 由 8.04 µA 降至 3.72 µA，规律一致。在产品固件配置中，加大 FD 检测间隔是降低待机功耗的有效手段，但需权衡手指响应速度。

**（4）Capture 模式波形特征。** Capture 波形为约 93 ms 周期的规则脉冲串：峰值约 16.9 mA，脉冲间低电平（Low）约 170~195 µA。两样品共 12 组测量结果高度一致（平均电流 1.83~1.95 mA），数据可信度高。

**（5）峰值电流对电源/供电设计的影响。** 模组峰值电流约 16.9 mA（3.3 V 下约 56 mW）。供电线路（LDO 或 DC-DC）建议按峰值电流预留 2~3 倍裕量，即选型不低于 50 mA 输出能力，以保证采集脉冲期间电压不跌落；本次测试电源限流设置为 3.07125 A，裕量充足。电池供电场景下，可按 FD 模式约 5 µA 的平均水平估算待机续航。

**（6）测量方法有效性。** 本次采用 Low（<0.02 A）量程 + Pulse 测量类型，µA 级基线与 mA 级脉冲均能清晰分辨，验证了 2.4/2.5 节所述测量与触发设置方法的有效性。样品 1 初测的三组异常数据（50 ms 组 Idle、100 ms 组 FD、300 ms 组 Idle）已经复测排除，全部数据有效。

## 五、总结

1. **掌握了 Agilent 663xx 电源仪器的使用方法。** 通过研读 14565A 软件官方快速入门指南，系统了解了软件的安装与 I/O 通信配置（GPIB/串口/VISA）、输出控制、波形测量、触发测量、游标分析、CCDF 统计与长时间数据记录等功能，形成了第二章的完整使用说明。
2. **完成了模组功耗实操测试。** 使用 Agilent 66311B（3.3 V 供电、Low 量程、Pulse 类型）经 14565A 软件完成 2 个 BF85112B 模组样品在 Idle、FingerDetect、Capture 三种模式、6 种检测间隔下的电流测量，记录了平均电流（Dc）与峰值电流（Max）并存档全部波形截图（附录 B、C）。结果表明：Idle 约 3.8~4.0 µA、FD 约 5.2~5.4 µA、Capture 平均约 1.9 mA/峰值约 16.9 mA，两样品一致性良好；FD 平均电流随检测间隔增大而降低（约 8.0 µA@50 ms → 3.7 µA@300 ms）。
