# 嵌入式学习路线规划（三阶段总览）

> 学习目标：从零掌握嵌入式软件开发，最终能独立开发 STM32 项目。

## 三阶段总览

| 阶段 | 主题 | 状态 | 需要硬件 | 内容 |
|------|------|------|---------|------|
| **第一阶段** | C 语言基础 | ✅ 已完成 | ❌ 不需要 | 变量、运算符、流程控制、函数、指针、数组、字符串 |
| **第二阶段** | C 语言进阶 + STM32 基础 | 🔄 进行中 | 2A 不需要 / 2B 需要 | 结构体、多文件工程、寄存器点灯、中断、定时器、串口 |
| **第三阶段** | 嵌入式深入与综合项目 | ⬜ 未开始 | ✅ 需要 | 库开发、FreeRTOS、综合实战项目 |

## 开发环境

- 系统：Windows
- 编译器：MSYS2 + MinGW-w64 (gcc 16.1.0)
- 编辑器：VS Code
- 版本控制：Git + GitHub
- 硬件（第二阶段购买）：STM32F103C8T6 蓝板 + ST-Link V2
