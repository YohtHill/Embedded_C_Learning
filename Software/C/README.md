- 位运算 `(1<<n)` 置位、`(v>>i)&1` 取位 = 寄存器读写基础

### 2026-08-12（D8 结构体 struct —— 2A-1 完成 ✅）

**今天完成的内容：**
- D8: 结构体定义（`struct`）、`typedef` 别名、声明与初始化、成员访问
- 作业：`student_t` 学生结构体，验证**值传递 vs 指针传递**（改副本 vs 改真变量，呼应 D4 的 swap 陷阱）
- 按值传整个结构体 = 复制一份，函数里改不到原变量；传指针才能改到

**核心收获（嵌入式思维）：**
- 结构体 = 把相关数据打包成整体（传感器温度+湿度+状态）
- **STM32 库的寄存器组 `GPIO_TypeDef` 就是结构体**，用结构体描述寄存器
- `typedef struct {...} 别名;` 是嵌入式最常用的写法，省去 `struct` 关键字
- 结构体按值传参开销大 → 大数据建议传指针

### 2026-08-12（D9 共用体 union + 枚举 enum —— 2A-2 完成 ✅）

**今天完成的内容：**
- D9: `union` 共用体（成员共享内存）、`enum` 枚举（命名整型常量）
- 作业1：用 union 判断**大小端**（`u.i=1` 看 `u.b` 是否为 1）
- 作业2：union 解析串口 4 字节数据帧（按字节读 / 按整型读，小端 `0x78563412`）
- 作业3：enum 定义 LED 状态机（OFF/ON/BLINK），模拟按键切换

**核心收获（嵌入式思维）：**
- **union = 同一块内存的多种视角**：寄存器高低字节访问（`Reg16.value` / `Reg16.byte.low/high`）
- **数据帧解析神器**：同一缓冲区既可按结构体读、也可按原始字节流读
- **enum = 状态机/错误码标准做法**：`LED_OFF=0, LED_ON=1, LED_BLINK=2`，`switch` 分发
- 小端机器：低位字节存低地址（本机 `bytes = 78 56 34 12`）
- `typedef enum {...} 别名;` 嵌入式常用写法

### 2026-08-12（D10 宏定义 #define —— 2A-3 完成 ✅）

**今天完成的内容：**
- D10: `#define` 宏定义 —— 预处理阶段的纯文本替换（不是函数！）
- 对象宏：常量/引脚/寄存器地址命名（消灭"魔法数字"）
- 函数宏：`MAX(a,b)`、`ABS(x)`、`IS_SET(reg,n)`，省去函数调用开销
- 括号陷阱：`SQUARE_BAD(2+3)=11`（忘加括号），`SQUARE_GOOD(2+3)=25`
- 条件编译：`#ifdef DEBUG` 调试开关、`#if/#elif` 平台选择、头文件保护
- 特殊宏：`__FILE__` / `__LINE__` / `__func__` / `__DATE__` / `__TIME__` 调试定位
- 作业：寄存器宏读写、MAX3、调试开关、`ASSERT` 断言报告宏

**核心收获（嵌入式思维）：**
- **宏 = 编译前文本替换**，发生在预处理阶段，无类型、无调用开销
- **寄存器地址宏**：`#define GPIOA_ODR (*(volatile unsigned int *)(基地址+0x0C))`
- **LED 位操作宏**：`LED_ON()` = `ODR |= (1<<pin)`，`LED_OFF()` = `ODR &= ~(1<<pin)`
- **调试开关**：`#ifdef DEBUG` 包住调试代码，发布时注释掉宏定义即自动剔除
- **断言宏**：`ASSERT(cond, msg)` 用 `__LINE__`/`__func__` 精确定位问题
- **头文件保护**：`#ifndef _XXX_H_ / #define ... / #endif` 防止重复包含

### 2026-08-13（D11 多文件工程 .h/.c 分离 —— 2A-4 完成 ✅）

**今天完成的内容：**
- D11: 多文件工程（`.h`/`.c` 分离 + 头文件保护）
- `.h` 头文件：只放**声明**（函数原型、宏、typedef、extern），并加 include guard
- `.c` 源文件：放**定义**（函数实现、全局变量），`static` 私有变量实现"封装"
- 多文件编译：`gcc lesson11_main.c led.c math_utils.c -o app.exe`（.h 不用出现在命令里）
- 作业：封装"温度传感器模块"（sensor.h/sensor.c），用结构体返回数据

**核心收获（嵌入式思维）：**
- **声明 vs 定义**：声明告诉编译器"这东西存在"，定义才真正分配内存
- **头文件 = 接口说明书**：别人只看 .h 就知道怎么用模块，不用看实现
- **include guard**：`#ifndef/#define/#endif` 防止头文件重复包含（D10 已预告，今天用上）
- **static 封装**：模块私有变量加 static，外部无法访问
- **嵌入式工程标准结构**：STM32 工程就是一堆 .c + .h 按模块组织（bsp_led.c / bsp_uart.c...）
