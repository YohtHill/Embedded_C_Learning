1.开始设计前，要了解客户需求的结构、芯片尺寸及型号、布件区域限制等，尤其是连接座位置及三色灯位置，一般来说基本固定位置，只可以进行细调，其中三色灯可以旋转调整位置，但要均匀摆放；布件时优先摆放连接座、三色灯、指纹芯片及金属环。

2.原理图导入PCB后，器件杂散，可以开启原理图与PCB交叉选择模式，把一个个模块（如主控接口模块、信号翻转模块、MCU模块、灯控模块、指纹芯片模块、电源模块、电机模块、蓝牙模块、晶振模块等）的器件单独放置一处，方便后续进行模块化布局。

3.器件布局时，要优先考虑SPI信号、高压信号、差分信号走线，可以旋转调整MCU及指纹芯片方向，使得对应信号尽量靠近且走线顺畅，这样可以减少信号过孔及走线长度，同时要注意信号隔离、差分等长等距等需求。

4.电源信号的去耦滤波电容及TVS管要优先就近靠近对应管脚摆放，其中指纹芯片电源VCC3_3V上的电容及TVS管优先靠近芯片的16-17脚即AVDD摆放。

5.连接座的管脚信号定义要按客户实际需求定义设置，不能单看原理图及封装，因为这两者是严格按照管脚位号来对应，有时会因为封装定义1脚方向的不同导致信号定义与客户要求刚好相反。

6.使用四层板时，如1层为指纹芯片层，2层为走线层，3层为GND完整层，4层为器件层，则芯片层主要走与指纹芯片连接的相关信号，灯控信号走线主要放至内层走线层，一般信号在器件层及走线层走线；

7.布件走线时，走线要优先经过滤波电容以及起保护作用的TVS管后再进入芯片或MCU对应管脚。

8.当板框较小而器件较多时，建议使用四层板设计，同时电源走线宽度按≥0.2mm设置，一般信号走线按≥0.1mm设置，过孔使用0.2/0.4；当板子空间充足时（如测试板及开发板），信号走线宽度可适当加大，同时过孔可使用0.3/0.5；当板子较大且较厚时，信号走线需加粗，同时过孔可使用0.5/0.8。

9.芯片层的GND铺铜与ESD-GND环之间需间隔0.5mm以上，同时GND铺铜需完整包裹信号走线及过孔以隔离ESD-GND信号。

10.设计芯片封装时，如指纹芯片及QFNQ封装芯片，若以底视图参考，则实际在画顶层封装时需镜像翻转。

11.芯片层的GND铺铜与ESD-GND环之间需间隔0.5mm以上，同时需优化调整信号过孔位置，使得GND铺铜能完整包裹其他信号；

12.电源走线及GND走线宽度应≥0.2mm

13.内层有误，应该为靠近芯片层（底层）的Inner2为走线层；

14.MCU的固定PAD至少打两个及以上过孔导通至其他层；

15.优化走线，使走线尽量短；

16.避免在芯片焊盘中打过孔，同时建议优化MISO过孔及走线，避免绕线过长；

17.避免在焊盘之间走线，以防焊接连锡误识；同时MCU电源走线应先经过电容及TVS管后再流入芯片；

18.ESD-GND电阻单点连接至连接座的GND PAD；

19.多打GND过孔导通各层的GND铜箔；
