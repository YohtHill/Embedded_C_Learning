一. 嵌入式指纹FD模式注意事项
1. FingerDetect 模式 指纹芯片电源供电有严格要求
2. LDO选型：
    2.1.指纹供电LDO输出电流建议≥250mA；
    2.2.选用快速响应的LDO；
3. 建议使用单独一个LDO给指纹模块供电。LDO输出走线一路给到指纹芯片常供电，分开一路用MOS开关控制给指纹模块算法MCU供电。
4. 指纹模块与其它模块共用LDO供电时，指纹模块供电在PCB Layout上需从LDO输出端单独走线

二. 指纹IC模组FPC设计规范
1. 选用合适尺寸的指纹IC型号；按实际项目IC大小做封装丝印
2. FPC中走线长度要求小于120mm；
3. 外围器件（电容、TVS管）到指纹走线距离≤30mm；
4. 、在预留粘贴黄色高温绝缘胶带或点胶空间情况下，建议FPC 结构外围元器区面积至少为3.0mm*3.5mm；若加上预留的走线空间，建议FPC 结构尺寸4.0mm*4.5mm。
5. 需要添加指纹导航功能的项目，模组FPC设计中指纹IC的A1管脚摆放位置需朝向连接器（金手指）PIN定义顺序的第1管脚。
6. 元器件边到板边建议要≥0.4mm;滤波电容需尽量靠近IC相关脚位并合理放置；
7. 板框边缘建议走0.2mm线宽的GND走线，若空间不足，可走0.15mm线宽；距离板框建议大于0.15mm；
8. AVDD、GND、HVDD、FVDD、FVSS走线宽度≥0.2mm ，VDDIO 走线宽度≥0.15mm ；在模组比较长的情况下，要适当加宽电源线和地线的走线；电源走线，应先到滤波电容，然后再从电容出线到芯片电源脚;
9. 、FVSS 与FVDD 优先并行走线，以减少其信号回路；FVSS,FVDD 与其它信号线之间需隔地；HVDD走线需使用0.1mm宽度以上地线与其它信号线隔离；FVSS,FVDD,HVDD背面禁止与其它信号走线重合；
10. SPI 信号线优先在同一层布线，走线尽量短且少过孔；CLK信号走线优选用GND屏蔽；MOSI,MISO之间使用地线隔离；如果空间不足时，可以使用INT、RST、CS隔离MOSI和MISO走线
11. 如果项目中有做RING 金属材质装饰环，可用RING 环泄放ESD 静电，建议Ring 环接ESD-GND,若外围器件有TVS管，则TVS管也连接ESD-GND，ESD-GND与系统地在连接器处短接；FPC 软板上与金属环连通的裸铜开窗至少两处,导通阻值<5 Ohm ；同一区域顶底层同时开窗接地，并在此区域增加导通过孔；
12. 层与层之间的信号走线应错开布线，避免平行重叠，如果一定要交叉，上下两层信号线必须垂直走线。
13. FPC走线，应平滑、分布均匀，尽可能走最短的线路，拐角应使用弧线代替弯线。
14. Top，Bottom层都要整板铺地，有补强的地方建议铺实铜，且两层铜箔之间多打过孔导通；其它地方建议采用栅格形式，网格铜推荐参数0.3mm，角度45°or 135°，线宽0.1mm，铺地和信号线之间的距离为0.15mm。
15. GND走线尽量要粗，至少加粗至0.2mm以上，尽量多打一些过孔；
16. TVS管的GND PAD多方向出线，连接到外围GND的线尽量加宽，多加过孔导通到背后的开窗区域，开窗区域尽量靠近TVS管和覆盖GND过孔。
17. 一般不允许出现一端浮空的布线，尤其是长距离的GND隔离线，主要是为了避免产生“天线效应，减少不必要的辐射干扰.
18. 过孔禁止打在钢片补强边缘，因折弯时容易破孔造成开路
19. 需要隔地的高频信号线走线空间过小无法走地线的时候，要与相邻的信号走线相隔至2条线宽的距离；
20. 金属补强一般需做接地处理，在对应的阻焊层(Solder Mask Top/Solder Mask Bottom)开窗。为可靠接地，建议多点开窗，开窗尺寸建议1.0mm以上，没空间时，尽量保证0.5mm以上；

三. LGA封装基板设计注意事项
1. FVDD,FVSS,VDDIO,AVDD,AVSS,HVDD,SVDD网络绑定PAD宽度≥0.2mm；
2. FVDD,FVSS,VDDIO,AVDD,AVSS,HVDD,SVDD,ESD_GND走线宽度需≥0.2mm，换层时至少使用2个过孔；
3. 固晶区域尽量有完整的FVSS网络铜箔，固晶区域铜箔比IC长和宽各大0.1mm，单边0.05mm；
4. 在DIE贴合面，最小切割尺寸周围做一圈ESD_GND环形铜箔，连接到ESD_GND焊盘PAD；ESD_GND环形铜做开窗处理；
5. 严格区分高、低压网络电路，良好隔离；低压信号线需用AVSS隔离保护
6. FVSS,FVDD与低压信号网络走线间距为线宽的2倍，如MOSI走线0.05mm，间距≥0.1mm；ESD_GND与其他信号网络间距≥100um；
7. SCLK与MISO信号线使用3W原则走线；SCLK_FIN与MISO_FIN信号线使用3W原则走线
8. 合封TVS管/电容布局优先靠近对应引脚；网络走线从焊盘PAD经过TVS管/电容，再连接到bonding PAD
9. 信号走线拐角使用圆弧
10. 每个走线层边沿需包地，铺铜以最小切割尺寸内缩0.1mm
11. 避免有一端悬空的条状的地；

四. ESD设计注意事项
1. 单sensor模组的ESD防护主要是以下几点：(1)金属环须接地（此为ESD防护最关键点），且需要单独接一条地线到主板（ESD‐GND），金属环的地线与模组的地线（GND）距离尽量远（>0.5mm）,模组的电源线和信号线用GND保护，且远离ESD‐GND；
2. 指纹模组的FVSS与GND的关系说明：
    2.1. FVSS是指纹sensor的地，FVDD是sensor的供电，FVDD和FVSS之间始终是
VDD电压（一般3.3V），但FVSS与GND之间的电压是变化的，采图时，FVSS
抬压到7V左右，而FVDD就抬压到7V+3.3V=10.3V左右；
    2.2. 指纹sensor的FVDD与FVSS有一个5V的TVS管（BF82160系列内封）；FVSS与GND有一个10V的TVS管，sensor表面的ESD空气放电有机会进入模组的电路内部，主要依靠这两个TVS管来防护
3. 指纹模组器件及线路点密封胶处理。指纹模组需要在sensor和元器件周围进行密封胶的点胶处理，目的是减震，防水，防止静电直接打入芯片引脚等等，密封胶尽量选择：
    3.1. a.具有良好的防潮,绝缘性能好；
    b.固化后胶体收缩率低,柔韧性佳,物理性能稳定;
    c. 胶水与芯片,基板基材粘接力强；
    d.耐高低温,耐化学品腐蚀性能优良；
    e.表干效果良好.
4. 闩锁效应（ latch up ）需要重点防范：
    4.1. 静电和指纹模组的供电电压快速波动都有可能产生芯片的闩锁效应发生，在智能门锁里，重点防范电机启动和关闭时引起的电源振铃现象，当指纹模组的排线和电机引线都比较长且靠近的结构,要特别注意电源退耦和引线的包扎，屏蔽处理；
    4.2. latch up 的防范，还需要注意在ESD测试和实际使用中，BF2080与主控端
    的spi通讯口的电平必须稳定，IO口上的过压同样可能引起闩锁效应，在门
    锁待机时，BF2080的RSTN和NSS脚是高电平，增加1K的串联电阻将减少电源
    波动时latch up产生的风险（BF82112内封BF2080）
    4.3. 在BF2080的供电端增加开关电路和自恢复保险电阻，主要是latch up发生
    后保护指纹芯片及快速断电并自恢复的作用，进一步提高ESD可靠性。
    F1选择保持电流为50mA的自恢复保险电阻，推荐型号：JK‐SMD0603‐005
    负载开关推荐使用AW35121；
    这个电路的工作原理：当指纹芯片发生latch up时，VDD上会产生大电流（
    大于300mA），超过F1的动作电流（150ma）,F1的电阻迅速变大，引起
    AVDD电压下降，电流变小，进而保护BF2080和指纹sensor;在这个过程中，
    BF2080会产生中断信号，汇报给主控芯片，主控芯片通过读取寄存器的标
    志判断是否为异常中断，如果是，就拉低BF2080_AVDD_EN信号，给BF2080
    断电，中断latch up 现象，然后再上电初始化，指纹模组恢复正常。
5. 指纹模组layout重点注意事项:
    5.1. 在指纹模组的PCB设计中，需要分清模组电路里的高压部分和低压部分，高
    压部分主要是指纹sensor（BF82160F或BF82192F）与BF2080之间的连接线路
    ，这部分电路在采图过程中都处于抬压状态（FVSS抬升到7V以上），因此
    在layout中需要严格区分高压电路和低压电路的走线区域，不能混在一起走
    线，也尽量避免并行，交叉，必要时用地线隔离.
6. 带算法芯片的指纹模组，同样要求金属环接独立的地线，ESD‐GND推荐通过连接器单独pin脚到主板，确因结构的问题，只有一个地线pin脚的连接定义，可以在连接器的地线脚旁边做单点接地处理
7. 算法芯片的供电端预留一个TVS管，控制指纹sensor的复位脚增加隔离电路，并加滤波电容，稳定复位信号；如果MCU有IO防电流倒灌功能，SPI的CS脚可以不加隔离电路。
8. 模组与主控端的接口保护也需要重点关注，串口的TX，RX须串联22欧电阻，INT
脚增加RC网络，防止干扰信号引起误触发主控，电源须做好退耦滤波处理，防止过
压干扰脉冲；
9. 对于带算法芯片的指纹模组，如果是小尺寸的圆形模组，建议走4层通孔板（第1
层为sensor层；第2层为走线层；第3层为地线层；第4层为元件层）；对于尺寸较大
的方形模组，可以使用2层通孔板；布局和走线尽量按以下要求设计。
10. 对于金属的接地layout（ESD‐GND）, 正确的走法是独立，干净的环地设计，与其
它走线用地线隔离（包括环地的第2层投影区），避免其它网络的过孔打在地环以内
11. ESD地环的第2层投影区用GND隔离其它走线，与GND网络的接入尽量在连接器的
接地处完成，并采用单点接地方式。
12. FVDD，FVSS为高压电路，线宽0.2~0.25mm,走线尽量短，且与复位，SPI等敏感线
路做好隔离；指纹sensor的TVS管靠近对应的pin脚，走线尽量短，线宽>0.2mm, TVS
管的接地脚与主地阻抗尽量小，避免走长线；MCU供电回路的TVS管靠近MCU的主供
电脚，且在电流通过的回路上

五. 指纹模组硬件设计注意事项
1. 主板的接口一般采用6pin连接器
2. 分别为两路供电，一路串口通讯UART，及模组输出到主控芯片的中断唤醒脚int; 算法芯片和指纹芯片的供电为3.3V 
3. 纹波要求在100mV内，特别是指纹芯片的供电VCC3.3V，在指纹芯片处于FD（手指检测）模式下，电压不能有明显波动，电压纹波始终保持在要求范围内
4. 指纹芯片供电LDO（VCC3.3V），建议选择电流≥250mA，静态电流小于5uA,且具有快速响应功能，当输出电流从0mA跳到100mA时，输出电压的变化小于100mV，如微盟电子的M6230系列；
5. 算法芯片供电LDO（MCU3.3）， 建议选择电流≥250mA，静态电流小于5uA，且具有掉电放电功能的LDO，如微盟电子的M6230系列
6. 在算法芯片与指纹驱动芯片之间的片选CS信号和复位信号增加了反相隔离电路，目的是防止在FD模式下，算法芯片的掉电引起BF2080的复位信号的不稳定以及改善漏电情况；C13具有增加复位信号的稳定性，消除电路干扰作用；R8，R13具有当算法芯片掉电后，保持反相电路的输入电平稳定；三极管最好选择Vgs最小大于1V的CMOS管，比如2N7002KM。
7. 板上须预留算法芯片软件烧录点及测试点；. 每一路LED灯的亮度可以通过修改串联的电阻值调整；
8. FVSS 与FVDD 优先并行走线，以减少其信号回路；FVSS、FVDD、HVDD走线需立体包地；
9. TVS管的GND PAD多方向出线，连接到外围GND的线尽量加宽，多加过孔导通到其它层的GND铺铜区域。
