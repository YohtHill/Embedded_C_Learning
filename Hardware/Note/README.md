## 知识点概览

### 1. 指纹模组设计（Intern_note.md）
- **指纹供电**：LDO 选型（输出电流 ≥250mA、快速响应），建议独立 LDO 供电
- **FPC 设计规范**：走线长度 <120mm、外围器件距走线 ≤30mm、电源线宽 ≥0.2mm
- **信号完整性**：SPI 信号同层布线、CLK 用 GND 屏蔽、上下层垂直走线
- **ESD 防护**：TVS 管接 ESD-GND、金属环泄放静电、GND 铺铜完整包裹信号

### 2. 模组设计技巧（Module_Design_Skills.md）
- **布局原则**：优先摆放连接座、三色灯、指纹芯片、金属环
- **模块化布局**：用原理图-PCB 交叉选择，把各功能模块分开放置
- **走线优先级**：SPI 信号、高压信号、差分信号优先，就近摆放滤波电容/TVS 管
- **四层板设计**：芯片层/走线层/GND 层/器件层，走线要经过电容和 TVS 再进芯片
- **封装设计**：底视图参考的芯片（QFN/QFN 封装）顶层需镜像翻转
