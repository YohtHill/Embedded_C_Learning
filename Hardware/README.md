# Hardware（硬件学习）

嵌入式硬件方向的学习内容，包括 **PCB 项目**、**实验测试**与**硬件设计笔记**。

## 目录

```
Hardware/
├── PCB_Prj/            # PCB 工程项目（3 个板卡设计）
├── ExperimentTest/     # 实验测试
│   ├── RippleTesting/      # 直流电源纹波与噪声测量
│   └── PowerSourceTesting/ # 电源测试模组（BF85112B）
└── Note/               # 硬件设计笔记（实习积累）
    ├── NOTE_File/          # 笔记文档
    └── Note_Img/           # 设计示意图（PCB/FPC/ESD/指纹模组）
```

## 内容概览

| 模块 | 说明 |
|------|------|
| **PCB_Prj** | PCB 工程设计项目（3 块板卡，含原理图/PCB/Gerber/BOM）|
| **ExperimentTest** | 硬件实验测试报告与数据（纹波、电源等）|
| **Note** | PCB 设计、FPC 软板、ESD 防护、指纹模组等设计经验 |

## 说明

- PCB 项目使用 Altium Designer 设计，每个项目含 SCH/PCB/Gerber/BOM/SMT 等完整文件
- 实验测试包含完整报告（.md）和分类图片
- 硬件笔记来自实习积累，包含大量设计规范与示意图
- → PCB 项目详情见 [PCB_Prj/README.md](PCB_Prj/README.md)
