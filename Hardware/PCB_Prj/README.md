## 每个项目的标准文件结构

```
项目名/
├── SCH/       # 原理图（.schdoc / .SchDocPreview）
├── PCB/       # PCB 版图（.pcbdoc）
├── Gerber/    # 生产文件（Gerber/ODB++，供 PCB 厂生产）
├── BOM/       # 物料清单（BOM，元器件采购用）
├── SMT/       # 贴片文件（坐标/位号，供 SMT 贴片厂）
├── DWG/       # 结构图（机械尺寸）
└── DXF/       # 外形/结构参考
```

## 文件类型说明

| 类型 | 用途 |
|------|------|
| `.schdoc` | Altium 原理图 |
| `.pcbdoc` | Altium PCB 版图 |
| Gerber 系列（.GTL/.GBL/.GTO...）| 生产光绘文件 |
| `.xlsx` / `.csv` | BOM 物料清单 |
| `.dwg` / `.dxf` | 结构机械图 |
| `.pdf` | 输出文档（图纸/报告）|
| `.zip` | 打包文件 |
